# Smart Search 环境引导与界面清晰化

## 界面及入口

保留概览、服务商、搜索与研究、活动、更新 Skills、设置与关于六项导航及现有功能。所有功能分组沿用原生卡片、标题、内边距和对齐。概览承担唯一完整本地环境管理和准备链路，设置管理App，Skills管理Agent接入；其他页仅在未就绪时显示状态与准备入口。

### Scenario: 保留导航功能与卡片风格
WHEN 浏览全部页面，THEN 六项导航与现有业务功能仍可访问，概览及App更新、环境、Skills等功能组保留统一卡片，未变成散放的文字和按钮。

### Scenario: 统一环境入口
WHEN 在设置、Skills及业务页面查看环境状态，THEN 不重复整套CLI管理；完整操作进入概览的本地环境区，未就绪时给清楚原因与可用的准备动作。

## 环境发现及引导

App通过外部Smart Search CLI提供配置和搜索能力；两者独立安装、更新与卸载。发现过程区分Node/npm、mise及Smart Search本身；沿全局shim和管理器解析真实工具路径，不只查询第一个npm prefix。固定正确的Node、包根目录、管理器和用户配置；多安装不静默切换，不改无关工具。

### Scenario: 发现mise全局shim及工具安装
WHEN Smart Search由mise单独管理且不在Node的npm全局prefix，THEN App沿shim/管理器找到实际安装并显示mise来源；探针无安装副作用，更新使用mise且保持该管理器所有权。

### Scenario: 发现普通npm及多安装
WHEN Smart Search由普通npm安装，或机器有多个Node/npm/工具安装，THEN 能找到并固定所选有效安装，手动选择可覆盖自动选择，安装/更新使用对应管理器和prefix，不覆盖其他安装或全局设置。

### Scenario: 旧格式安全兼容与可解释失败
WHEN 已有旧版包装器或损坏/不兼容安装，THEN 不自动执行会下载Python的bootstrap；可安全确定已准备运行环境及兼容协议时连接，否则明确是旧版/不兼容/损坏并给更新或手动下载路径，不简单标作未安装。

### Scenario: 首次准备直到配置和测试
WHEN 没有可用环境，THEN 概览显示当前步骤及下一动作，按需引导获取Node/npm、安装/更新或定位Smart Search，完成后自动验证连接并继续配置服务商、显式测试及可选Skills；已完成步骤复用，不因移动App目录重装。

### Scenario: 断线和发行阻塞可以恢复
WHEN 用户进入服务商等页面但CLI不可用，或网络失败/兼容版本尚未发布，THEN 页面解释实际状态并提供准备/重试/手动获取动作，不停在“本地引擎未连接”；无法安装时不展示假成功或无效下载。

## App 更新

一个主要按钮：检查更新→下载更新→实际进度/必要安全重启。新进程启动执行自动检查，取消以24小时作为UI承诺与常驻调度。手动检查始终可用；原生框架签名校验、差分回退和草稿保护保留。散包明确安装版要求，不冒充已安装更新客户端。

### Scenario: 单一更新动作与启动检查
WHEN 启动两次App且间隔不到24小时或手动检查，THEN 每次启动均检查（支持更新的安装包且偏好开启），发现新版后原按钮变为下载更新；无重复检查/跳过操作阵列，下载和安装状态真实，失败可重试。

## 字段帮助

API地址、模型、路由、Key与配置目录都提供用途、必填条件、默认/留空行为、格式和示例。意图路由说明问题所需能力；hybrid模型增强可选；向量/分类填写完整endpoint，TypeSafe使用base URL。问号悬浮或键盘焦点显示帮助，可点击查看详情；空字段显示占位，输入后让位，不能替代真实标签或保存为用户值。

### Scenario: API与路由字段可理解
WHEN 查看或填写服务商/路由字段，THEN 每个字段都有相关而非仅内部变量名的说明和适用示例，地址合同正确；帮助支持鼠标和键盘，示例/默认/真实值清楚区分，Key不泄露。

## 保护与验证

保留并发、草稿、文件来源/路径校验、备份和原子写入。错误如实显示；自动检测无安装或真实API调用副作用。Windows/macOS中文英文语义一致，使用原生控件与现有资源系统。

### Scenario: 保留数据与管理器边界
WHEN 检测、安装失败、切页、取消或更新，THEN 配置/Key/结果/Skills和未保存工作受保护；不自动迁移、更改管理器或删除任何用户文件。

### Scenario: 可运行验证与双端一致
WHEN 交付候选，THEN 环境发现、步骤恢复、更新、字段帮助和UI资源有可运行回归，Windows构建与实际mise只读检测留有证据；Mac编译和GUI分别标记实际覆盖情况，未经授权不发布或替换正式安装。
