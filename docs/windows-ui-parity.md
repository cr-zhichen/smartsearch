# Windows 界面层级迁移

在 `codex/macos-native-adaptation` 分支上，以 `be622b1` 为迁移起点。迁移 macOS 已确认的信息层级与交互，保留 WinUI 的 NavigationView、列表、开关、Flyout 和 ContentDialog；共用 Python 后端与中英文词库。阶段完成后分别提交推送，整体验收后再创建上游 PR。

## 第一阶段：基础布局、设置与操作提示

- 设置保留单页滚动：顶部项目图标、版本和 GitHub，下面依次为通用、App 更新、独立 CLI 和高级。控件对齐到设置行右侧，CLI 更新、运行环境和内置入口各自有明确边框。
- 操作提示移到固定工具栏入口和 WinUI Flyout，完整文字可选取，长文可滚动，支持关闭后查看和清除；提示不再占据页面布局行。
- 提供共用分栏容器：明确初始／最小／最大栏宽，拖动和方向键调整，按页面保存；窄窗口改为上下组织，不以选中内容的宽度重新测量。滚动位置按页面或 pane key 独立保存。
- 语言切换统一通过 `ApplyState()` 更新快照，覆盖 Skills 状态；工具栏与页面一起刷新。运行环境在设置页也能接收异步状态。
- `mise.toml` 使用本机已安装且符合项目约束的 .NET SDK 8.0.422，新增 Windows 编译、后端依赖与打包任务。

验证：在现有 UTM Windows x64 虚拟机中，用隔离目录 `C:\smartsearch-ui-lab\stage1` 和由 mise 管理的工具链原生编译，最终为 0 警告、0 错误。未新增或运行 UI 单元测试。此阶段为编译验证，尚未声称实机布局验收。
